# Calculadora de Índice de Masa Corporal (IMC) 🐍

Este es un proyecto en *Python* que permite calcular el estado nutricional de una persona basándose en su peso y altura.

## Funcionalidades
* Cálculo preciso del IMC.
* Clasificación según los estándares de salud.
* Interfaz amigable en consola.

## Cómo ejecutarlo
1. Clona el repositorio.
2. Ejecuta python 1.CalculadoraIndiceDeMasaCorporal.py.
